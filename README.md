# Basem Madian Books

Author site with free audio for Basem Elguoshy Madian's books.

- `index.html` — the public site (reads `data.json`)
- `admin.html` — the control panel for adding and editing books, audio, covers and samples
- `data.json` — all site content (edited by the control panel)
- `audio/`, `covers/`, `samples/` — uploaded files

Each book's QR code links to `https://<site>/?b=<book-id>`.
